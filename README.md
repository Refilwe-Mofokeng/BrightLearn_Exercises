# SQL Fundamentals & Advanced SQL Exercises

## Overview
This repository contains a series of SQL exercises designed to build and strengthen foundational and intermediate data analysis skills using structured queries.

The exercises progress from SQL basics to more advanced concepts such as NULL handling and DATE functions.

---

## Structure of Exercises

There were six exercises, each targeting a specific SQL skill set:

### 1. SELECT & Filtering Statements
Focused on retrieving and filtering data from tables using:
- `SELECT`
- `DISTINCT`
- `ORDER BY`
- `LIMIT`
- `WHERE`
- Logical operators (`AND`, `OR`, `NOT`)
- `IN`
- `BETWEEN`

Objective:  
Learn how to extract relevant subsets of data based on specific conditions.

---

### 2. Aggregate Functions & Grouping
Explored how to summarise data using:
- `SUM`
- `COUNT`
- `AVG`
- `MIN`
- `MAX`
- `GROUP BY`
- `HAVING`
- `ORDER BY`

Objective:  
Understand how to aggregate data to generate insights at a grouped level (e.g., totals, averages, counts).

---

### 3. CASE Statements
Introduced conditional logic within SQL queries:
- `CASE WHEN`
- Creating derived columns
- Categorising data dynamically

Objective:  
Enable more advanced analysis by transforming raw data into meaningful segments (e.g., categories, performance bands, buckets).

---

### 4. Joins, Unions, Filtering & Aggregation
Combined multiple SQL concepts to solve more complex business problems:
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- `UNION`
- Filtering with `WHERE`
- Logical operators (`AND`, `OR`, `NOT`, `IN`)
- Aggregations with `GROUP BY` and `HAVING`
- `ORDER BY`

Objective:  
Understand how to combine datasets and perform multi-step analysis across tables.

---

### 5. Advanced SQL – NULL Functions
Focused on handling missing or incomplete data using NULL functions.

Concepts covered:
- `IFNULL()`
- `ISNULL()`
- `COALESCE()`

Practical applications included:
- Replacing NULL salary values with defaults
- Handling missing department names
- Identifying NULL records
- Replacing missing dates with status labels
- Counting NULL values
- Selecting the first available non-NULL value across multiple columns

Objective:  
Learn how to manage missing data effectively to ensure cleaner analysis and more reliable outputs.

---

### 6. Advanced SQL – DATE Functions
Focused on working with dates, timestamps, and date calculations.

Concepts covered:
- `DATEADD()`
- `DATEDIFF()`
- `CURRENT_DATE`
- `CURRENT_TIMESTAMP`
- `DATE_FROM_PARTS()`
- `DATE_PART()` / `EXTRACT()`
- `TO_DATE()`
- `TO_CHAR()`

Practical applications included:
- Adding months and years to dates
- Calculating days between dates
- Measuring time elapsed from a given date
- Extracting date components (year, hour, minute)
- Formatting dates into readable strings
- Creating dates from separate year, month, and day values

Objective:  
Develop the ability to manipulate, calculate, and format date/time data for reporting and analysis.
